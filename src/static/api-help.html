Built-in API Help

doc2pdf API reference

This page is served directly by the running service. Use it as a quick reference for available endpoints, payloads, and supported flows.

Also available: OpenAPI Swagger UI and ReDoc.

GET/healthz

Basic liveness check.

{
  "status": "ok",
  "gotenberg_base_url": "http://127.0.0.1:3000"
}
POST/convert/doc-to-pdf

Stable backend-facing conversion endpoint. Requires X-Shared-Token.

{
  "attachment_id": "att_123",
  "source_url": "https://storage.example/source.doc",
  "target_url": "https://storage.example/preview.pdf",
  "source_filename": "legacy.doc",
  "target_filename": "preview.pdf",
  "request_id": "req-001"
}

Response:

{
  "status": "ready",
  "attachment_id": "att_123",
  "preview_mime": "application/pdf",
  "preview_size_bytes": 123456,
  "error_code": null,
  "error_message": null
}
POST/mvp/prepare-upload

Hosted-upload preparation for browser clients without their own storage.

{
  "filename": "legacy.doc",
  "content_type": "application/msword"
}

Response includes direct upload URL, upload headers, preview URL, and opaque conversion token.

POST/mvp/convert

Finalize hosted-upload conversion after the browser uploads the source directly to Object Storage.

{
  "conversion_token": "opaque-short-lived-token"
}

Response shape matches the MVP upload response and includes preview_url on success.

Supported flows

Bring your own storage

  1. Client prepares presigned source_url.
  2. Client prepares presigned target_url.
  3. Client calls POST /convert/doc-to-pdf.

Hosted upload

  1. Client calls POST /mvp/prepare-upload.
  2. Client uploads the document directly to Object Storage.
  3. Client calls POST /mvp/convert.
  4. Client opens preview_url.

Common error details

  • 401 missing or invalid X-Shared-Token for /convert/doc-to-pdf.
  • 400 filename is required for /mvp/prepare-upload.
  • 400 conversion_token is required for /mvp/convert.
  • 400 invalid/expired conversion token (Invalid conversion token format/signature or Conversion token expired.).
  • 500 missing storage credentials when Lockbox/env is not configured.
